# Contributing to WhatsApp AI Assistant

Thank you for your interest in contributing! 🎉

## How to Contribute

1. **Fork** the repository
2. **Clone** your fork locally
   ```bash
   git clone https://github.com/<your-username>/whatsapp-ai-assistant.git
   cd whatsapp-ai-assistant
   ```
3. Create a new branch for your feature/fix
   ```bash
   git checkout -b feat/your-feature-name
   ```
4. Make your changes
5. Ensure the app still works (`docker compose up` or local run)
6. Commit following [Conventional Commits](https://www.conventionalcommits.org/)
   ```bash
   git commit -m "feat: add support for voice messages"
   ```
7. Push your branch and open a Pull Request

## Code Style

- Follow PEP 8
- Prefer clear function/variable names
- Add docstrings to public functions
- Keep LLM prompt engineering clean and well commented

## Reporting Bugs

Please use the GitHub issue template for bug reports. Include:
- Steps to reproduce
- Expected vs actual behavior
- Environment (Python version, Docker yes/no)
- Relevant logs

## Feature Requests

We love new ideas! Open an issue with label `enhancement` and describe the use case.

## Pull Request Checklist

- [ ] Code is formatted and readable
- [ ] New functionality has comments/docstrings
- [ ] README or docs updated if behavior changes
- [ ] No secrets or keys committed

Thank you for helping make this project better!
